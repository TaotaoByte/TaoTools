# 用 AI 高效输出周报与工作总结

写周报是很多人的「甜蜜负担」：明明做了不少事，一坐下来却不知道从何写起。其实只要掌握正确的提示词方法，AI 完全可以把散乱的工作记录整理成一份有条理、有重点的周报。本文分享一套可复用的思路与模板。

## 一、直接口述不如给「半成品」

很多人让 AI 写周报，只丢一句话「帮我写周报」，结果得到的往往是大而空的套话。原因是 AI 缺少你本周的真实工作细节。

正确做法是：**你先提供原始素材（哪怕是零碎的记录），再让 AI 归纳整理**。你的角色是「提供事实」，AI 的角色是「组织表达」。

## 二、周报提示词模板

以下是一个可直接套用的模板，把方括号里的内容替换成你的真实信息：

```text
请帮我把下面的工作记录整理成一份周报，要求：

1. 按「本周完成 / 进行中 / 下周计划 / 风险与求助」四部分组织；
2. 每一条用「做了什么 + 带来了什么结果/进展」的结构，突出数据和结果；
3. 语气专业、简洁，避免空话套话，不夸大；
4. 总字数控制在 300 字以内。

工作记录：
- [这里粘贴你的工作记录，如：完成了登录模块的开发，联调通过]
- ...
```

## 三、让 AI 帮你「复盘」

除了流水账式的记录，好的周报还应该有关键的复盘与思考。可以用这条提示词：

```text
基于我本周的工作，帮我做一次复盘：
1. 做得好的地方，值得沉淀的经验；
2. 遇到的问题及原因分析；
3. 可以改进的地方及具体建议。
```

把复盘结果提炼进周报，能让上级看到你的思考深度。

## 四、月报 / 季度总结的差异

周报侧重「进度」，月报和季度总结更侧重「成果与价值」。切换提示词时，重点从「做了什么」转向「达成了什么目标和影响」：

```text
请把以下素材整理成月度总结，重点突出：
1. 本月的关键成果（尽量用数据量化）；
2. 与上月相比的进展；
3. 对团队/业务的价值贡献。
```

## 五、几个提效小技巧

1. **平时随手记**：建立一份个人工作日志，每天花 1 分钟记录关键动作，周末只需把日志喂给 AI。
2. **别让 AI 编数据**：没有真实数据就标注「暂无」，宁可诚实也不要夸大。
3. **保留个人语气**：AI 生成后再人工润色，加入一两句自己的观察和语气，避免千篇一律。
4. **建立个人模板库**：把调好的提示词保存下来，每周复用。

## 六、总结

用 AI 写周报的核心不是「偷懒」，而是把时间花在更有价值的思考和结果上。记住这个公式：**你的真实素材 + 结构化提示词 = 一份体面又有内容的周报**。当你把这套方法固化下来，写周报的时间会从半小时缩短到五分钟。
