# 用 AI 提升写作效率的 5 个场景

## 1. 大纲生成

输入主题，让 AI 帮你梳理文章结构。

```text
请帮我写一篇关于「AI 辅助编程」的文章大纲，包含 5 个核心要点。
```

## 2. 初稿撰写

根据大纲快速生成初稿，然后人工修改。

```text
请根据以上大纲，撰写一篇 1500 字左右的初稿。
```

## 3. 润色改写

让 AI 优化表达，调整语气和风格。

```text
请将以下内容改写得更专业、更简洁。
```

## 4. 标题优化

生成多个标题选项，选择最吸引人的。

```text
请为这篇文章生成 10 个标题，要求简洁有力。
```

## 5. 多语言翻译

快速将内容翻译成其他语言。

```text
请将以下中文翻译成自然流畅的英文。
```

## 使用建议

- AI 适合辅助，不适合替代思考
- 重要内容需要人工核对事实
- 保持自己的写作风格和声音
