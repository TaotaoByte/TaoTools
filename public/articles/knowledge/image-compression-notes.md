# 图片怎么压才合适

一张原本只在文章里显示 800 像素宽的配图，没必要直接放上相机原片。先明确展示尺寸，再处理体积，通常比一味调低质量更有用。

## 一个可直接照做的顺序

1. 保留原图，压缩结果另存为新文件。
2. 在本站的[图片压缩工具](/tools?tool=image-compress)选图，把最大边长设置为实际需要的尺寸。例如文章正文配图先尝试 1600 像素，给高密度屏幕留一点余量。
3. 从 WebP、80% 质量开始，检查文字边缘、阴影和颜色过渡。
4. 下载后查看实际文件大小，并在文章页面用手机检查清晰度。

这里的尺寸和质量只是起点。截图里的小字、照片里的纹理，对压缩的敏感程度不同，最终以实际观感为准。

## 怎么选格式

- **照片、文章封面：** 可先试 WebP 或 JPEG，放大检查纹理是否明显模糊。
- **透明背景素材：** 可先试 WebP。JPEG 不保留透明区域，本站会填成白色。
- **密集文字截图：** 尝试较高质量 WebP，不要为了体积牺牲可读性。
- **动画图片：** 保留原动画；本站压缩工具只导出首帧。

## 为什么导出反而变大

压缩不是对任何文件都能继续变小。原图可能已经压过，改用另一种编码或更高质量，体积可能增加。比较实际字节数比只看质量滑块可靠。

浏览器通过 Canvas 导出图片；不支持指定格式时，可能退回 PNG。工具会按实际输出类型生成扩展名。这个工具适合网页配图，不适合需要保留专业色彩配置和完整原片元数据的场景。

## 关于隐私

本工具读取本地文件并在浏览器内处理，不调用上传接口。外部图片处理网站有各自的数据政策，需要另外查看。
