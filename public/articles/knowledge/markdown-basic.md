# Markdown 基础语法速查

## 1. 标题

```markdown
# 一级标题
## 二级标题
### 三级标题
```

## 2. 段落与换行

段落之间用空行分隔。

## 3. 强调

```markdown
**粗体**
*斜体*
~~删除线~~
```

## 4. 列表

无序列表：

```markdown
- 项目一
- 项目二
  - 子项目
```

有序列表：

```markdown
1. 第一步
2. 第二步
```

## 5. 链接与图片

```markdown
[链接文字](https://example.com)
![图片描述](https://example.com/image.png)
```

## 6. 代码

行内代码使用反引号：`console.log()`

代码块：

```javascript
function hello() {
  console.log('Hello, Markdown!');
}
```

## 7. 引用

```markdown
> 这是一段引用文字。
```

## 8. 分隔线

```markdown
---
```

## 9. 表格

```markdown
| 姓名 | 年龄 |
|------|------|
| 张三 | 25   |
| 李四 | 30   |
```
