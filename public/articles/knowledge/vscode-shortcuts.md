# VS Code 提高效率的快捷键

## 编辑

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + P` | 快速打开文件 |
| `Ctrl + Shift + P` | 命令面板 |
| `Ctrl + Shift + F` | 全局搜索 |
| `Ctrl + /` | 注释/取消注释 |
| `Alt + ↑/↓` | 移动当前行 |
| `Ctrl + D` | 选中下一个相同词 |
| `Ctrl + Shift + L` | 选中所有相同词 |

## 导航

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + G` | 跳转到指定行 |
| `F12` | 跳转到定义 |
| `Alt + ←` | 返回上一个位置 |
| `Ctrl + Tab` | 切换标签页 |

## 终端

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + \`` | 显示/隐藏终端 |
| `Ctrl + Shift + \`` | 新建终端 |

掌握这些快捷键可以显著提升日常开发效率。
