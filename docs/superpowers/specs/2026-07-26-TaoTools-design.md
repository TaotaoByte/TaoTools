# TaoTools 设计规格文档

## 1. 项目概述

开发「TaoTools」个人工具导航与知识分享网站，定位是"实用工具箱 + 资源导航 + 知识库"综合平台。后续部署到 Ubuntu 24.04 服务器（2核2G），构建产物需轻量、性能友好。

参考设计风格 `https://wikimind.top/` 的简洁、数据感、卡片式布局思路，但不照搬，形成独立风格。

## 2. 核心设计原则

- **配色**：浅色主题以白/米白/浅灰为底，主色调为靛蓝（indigo），深色主题为深灰蓝（slate），舒适不刺眼。
- **设计感**：现代感，善用圆角、微阴影、渐变、毛玻璃效果；卡片带 hover 动效。
- **交互感**：滚动渐入动画、按钮反馈、数字计数动画、主题切换过渡动画。
- **字体**：中文使用系统字体栈，英文使用 Inter / Geist 等现代无衬线字体。

## 3. 技术栈

- 前端框架：React 18 + Vite
- 样式方案：Tailwind CSS
- 路由：React Router（hash 模式）
- 图标：Lucide React
- 动画：Framer Motion
- 状态管理：React Context（主题切换）
- Markdown 渲染：react-markdown + react-syntax-highlighter
- 构建产物：静态 HTML/CSS/JS，Nginx 托管

## 4. 网站结构

### 4.1 顶部固定导航栏

- 左侧：Logo「TaoTools」+ slogan「一站式工具导航与知识分享平台」
- 中间/右侧：首页 | 工具箱 | 资源库 | 软件推荐 | AI 中心 | 知识库 | 主题切换按钮
- 移动端：汉堡菜单展开导航

### 4.2 首页（/）

- **Hero 区域**：大标题、副标题、简短介绍、"开始探索"按钮（平滑滚动到下方板块），背景为淡渐变或几何装饰。
- **数据统计区**：4 个卡片，数字从 0 滚动到目标值（1.5 秒）：工具数量、访客人数、教程章节、收获点赞。
- **板块快捷入口**：6 个大卡片（2 行 3 列 / 移动端 1 列），图标、标题、一句话描述、hover 放大+阴影。
- **最新更新/推荐区**：3-4 个最近更新内容卡片，带标签、日期、简短描述。

### 4.3 工具箱（/tools）

- 页面标题 + 实时搜索过滤
- 分类标签：全部 | 文本处理 | 编码转换 | 图片工具 | 计算工具 | 其他
- 工具卡片网格：图标、名称、描述、使用按钮
- **内置工具**：文本对比、JSON 格式化/压缩/转义、Base64 编解码、时间戳转换、正则测试、颜色转换器、密码生成器、文本字数统计
- **外部工具**：卡片标注"外部工具 ↗"，新标签页打开

### 4.4 资源库（/resources）

- 分类：设计模板 | 视频素材 | 图片壁纸 | 图标字体 | 学习资源
- 资源卡片：网站名称、图标/截图、介绍、标签、跳转链接
- 点击新标签页打开
- "收藏"标记功能（localStorage）

### 4.5 软件推荐（/software）

- 分类：开发工具 | 效率办公 | 设计创作 | 系统工具 | 媒体播放
- 软件卡片：图标、名称、平台标签、推荐语、官网链接、免费/开源/付费标签

### 4.6 AI 中心（/ai）

- **AI 大模型排名**：表格/卡片展示主流模型（GPT-4o、Claude、Gemini、Kimi、文心、通义等），字段包括模型名、厂商、上下文长度、特点、官网链接、免费额度。
- **AI 教学**：文章列表，含标题、标签、摘要、阅读时间。
- **AI 实用技巧**：Prompt 模板和技巧卡片，带"一键复制"按钮。

### 4.7 知识库（/knowledge）

- 分类：Markdown 语法 | 开发笔记 | 软件安装配置 | 效率技巧 | 其他
- 文章列表，支持按分类筛选
- 文章详情页：Markdown 渲染、代码高亮、目录导航

### 4.8 页脚

- 网站简介、联系方式（GitHub/邮箱）、备案信息占位、友情链接占位
- 版权信息：© 2025 TaoTools

## 5. 交互与动画

1. **页面切换**：Framer Motion 路由切换动画（淡入 + 轻微上滑）
2. **滚动动画**：元素进入视口时 fade-in + translateY， stagger 加载
3. **数字动画**：首页统计数据计数动画，持续 1.5 秒
4. **Hover 效果**：卡片 hover 上浮 translateY(-4px) + 阴影加深，按钮 hover 颜色过渡
5. **主题切换**：全站平滑切换浅色/深色模式，Tailwind `dark:` 前缀，localStorage 保存用户偏好，默认跟随系统
6. **加载状态**：页面初始加载简洁 Logo 动画（1 秒内）

## 6. 响应式设计

- **桌面端（>1024px）**：导航栏完整展开，多列网格，侧边栏布局
- **平板端（768px-1024px）**：导航栏可能收缩，网格 2 列
- **移动端（<768px）**：汉堡菜单，单列布局，卡片全宽，字体适当放大
- 所有交互元素移动端最小 44px 触摸区域

## 7. 性能与部署

- 构建产物轻量，首屏加载控制在合理范围
- 图片懒加载
- 代码分割：React.lazy + Suspense 按路由懒加载
- 输出为静态文件，Nginx 托管
- 路由使用 Hash 模式，避免刷新 404

## 8. 数据组织

所有展示数据（工具列表、资源列表、文章列表、软件列表等）以 JSON 文件形式组织在 `src/data/` 目录下，组件不硬编码数据。

## 9. 初始内容策略

- 主色调：靛蓝
- 首页统计数字使用合理示例值（如工具 50+、访客 12,580+、章节 80+、点赞 3,200+）
- 工具、资源、软件、AI 模型、知识库文章填充真实可用的示例数据
- 后期可通过修改 JSON 文件扩展
